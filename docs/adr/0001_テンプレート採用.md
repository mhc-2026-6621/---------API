# ADR-0001: サービス標準テンプレートを採用する

## Status

Accepted

## Context

複数サービスを同じワークスペースで扱うため、設計資料と実装コードの置き場所、命名、責務分離をそろえる必要がある。

## Decision

サービスフォルダ直下に `docs/` と `app/` を置き、設計資料と実装本体を分離する。実装は `app/src/` 配下に集約する。

## Consequences

- サービス間で資料とコードの探し方がそろう。
- PoCから本番化する際の差分管理がしやすい。
- 設計ドキュメントの番号体系がテンプレートと統一された。
- 旧形式のドキュメントは削除し、番号付きドキュメントを正本に一本化した。
