# フォルダ構成・ファイル構成

このプロジェクトは Next.js App Router の標準に合わせて、実装コードを `app/src/` 配下に集約しています。サービスフォルダ直下に `docs/`（設計資料）と `app/`（実装本体）を置き、責務を分離しています。

## 参照ルール

- `@/` は `app/src/` を指します。例: `@/types`, `@/lib/format-utils`
- 画面専用部品は、利用する画面フォルダ直下の `_components/` に置きます。
- 複数画面で使う部品だけを `app/src/components/shared/` に置きます。
- APIルートは `app/src/app/api/` に置き、業務計算は `app/src/lib/` へ分離します。
- 静的ファイルは `app/public/`、テストは `app/tests/`、ローカル実行時データは `app/data-store/` に置きます。

## 命名方針

| 種別 | 置き場所 | 方針 |
|------|----------|------|
| 画面 | `app/src/app/**/page.tsx` | URL構造に合わせる |
| 画面専用部品 | `app/src/app/**/_components/` | 利用画面の近くに置く |
| 共通部品 | `app/src/components/shared/` | 2画面以上で使うものだけ置く |
| 業務ロジック | `app/src/lib/` | UIから分離し、APIと画面の両方から使える形にする |
| モックデータ | `app/src/data/` | PoCの初期データと状態管理を置く |
| 型定義 | `app/src/types/` | 業務概念ごとに分け、`app/src/types/index.ts` で再エクスポートする |
