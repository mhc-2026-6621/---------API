# UI・デザインガイドライン

## デザイン原則

- 金融機関の業務システムとB2B EC SaaSの中間的なトーン
- 月額ファイナンスの訴求を商品詳細に組み込み、購入導線を自然に接続
- 全ページにPoC注記を表示

## レイアウト

| 領域 | 用途 | 備考 |
|---|---|---|
| ヘッダー | ロゴ、ナビゲーション、ロール切替 | ロールに応じてナビ項目変更 |
| メイン | 業務画面 | |
| フッター | PoC注記 | 全ページ共通 |
| APIパネル | APIコール確認ドロワー | 右下フローティングボタン |

## コンポーネント方針

- UIコンポーネント: shadcn/ui（Button, Card, Dialog, Table, Badge, Tabs等）
- ステータスバッジの色分け: 即時試算可→グリーン、仮審査可→ブルー、要個別見積→アンバー
- 月額表示: ティール色の大きなフォントで目立たせる

## 表記ルール

| 種別 | ルール | 例 |
|---|---|---|
| 日付 | `yyyy/MM/dd` | `2026/05/20` |
| 金額 | 円、3桁区切り、¥プレフィックス | `¥12,800,000` |
| 月額 | 「月額」プレフィックス＋ティール色 | `月額 ¥245,000〜` |
| ステータス | カラーバッジ | `仮承認` `否決` |
