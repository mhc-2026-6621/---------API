# サービス概要

## 目的

- このサービスで解決する業務課題: 高額B2Bアセット購入時のファイナンス手続きを、EC購入フローに組み込む
- 利用者が得る価値: 商品ページから月額試算→仮審査→契約までシームレスに完結
- 既存業務・既存システムとの関係: B2B ECサイトへのAPI組み込みを想定

## サービス名

**エンベデットリースAPI**

## コンセプト

国内B2B EC上で高額アセット（建機・産業機械等）の購入時に、リース/割賦ファイナンスを「EC決済のように」組み込めるAPIプロダクト。

「Quote-to-Finance」の全フローをカバーする：
商品ページ → 月額試算 → 仮審査 → 本審査 → 電子契約 → 納品/検収 → 販売店支払 → 月額請求 → 満了処理

## 対象ユーザー

| ロール | 主な目的 | 利用頻度 | 備考 |
|---|---|---:|---|
| 買い手企業（Buyer） | 高額設備を月額で導入 | 随時 | 中小企業・個人事業主・工場・建設会社等 |
| EC事業者/販売店（Merchant） | ファイナンス導線で成約率向上 | 日次 | 高額アセットを販売するB2B EC事業者 |
| ファイナンス管理者（Finance Admin） | リスク評価・ステータス管理 | 日次 | リース会社・割賦販売会社の審査担当 |

## スコープ

### 対象範囲

- 商品一覧・詳細表示（マーケットプレイス）
- 月額ファイナンス試算（即時見積）
- 仮審査申込・結果表示
- ファイナンス管理者による審査・ステータス管理
- 販売店ダッシュボード（申込状況・支払予定）
- APIコール確認パネル（デモ用）

### 対象外

- 本審査・電子契約・実際の融資実行
- 外部API・外部DB連携
- 認証・認可（ロール切替UIで代替）

## 対象アセットカテゴリ

- 中古建機（油圧ショベル等）
- フォークリフト
- 工作機械（マシニングセンタ等）
- 産業機械
- 業務用厨房機器
- 冷凍冷蔵設備
- ロボット・搬送設備

## 主要機能

| 機能 | 概要 | 優先度 | 備考 |
|---|---|---|---|
| マーケットプレイス | アセット一覧・検索・詳細表示 | Must | 商品カード形式 |
| 月額試算 | リース/割賦の月額シミュレーション | Must | POST /api/finance/quotes |
| 仮審査申込 | 法人情報入力→仮審査→結果表示 | Must | POST /api/applications |
| 管理者ダッシュボード | 審査キュー・リスクスコア・ステータス管理 | Must | Finance Admin向け |
| 販売店ダッシュボード | 申込一覧・KPI・支払予定 | Must | Merchant向け |
| APIコール確認パネル | APIリクエスト/レスポンスの可視化 | Must | デモ訴求用 |

## 技術スタック

| 項目 | 技術 | 備考 |
|---|---|---|
| フレームワーク | Next.js 14 (App Router) | TypeScript |
| UI | React 18 + shadcn/ui | Tailwind CSS |
| データ | インメモリ（TypeScript配列） | 再起動でリセット |
| 認証 | なし | ロール切替UIで代替 |

## 成功指標

| 指標 | 現状 | 目標 | 測定方法 |
|---|---:|---:|---|
| デモシナリオ完走率 | - | 100% | 3シナリオすべて操作可能 |
| API可視化の理解度 | - | 高 | デモ後フィードバック |

## 前提・制約

- 技術制約: フロントエンドのみ、外部API・外部DB不要、npm run devで即起動
- 業務制約: 本番審査・融資実行は行わない、すべて架空データ
- セキュリティ/法務制約: 実在企業情報不使用、全ページにPoC注記表示
