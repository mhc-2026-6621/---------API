## 1. プロダクト概要

### 1.1 サービス名

**エンベデットリースAPI**

### 1.2 コンセプト

国内B2B EC上で高額アセット（建機・産業機械等）の購入時に、リース/割賦ファイナンスを「EC決済のように」組み込めるAPIプロダクト。

「Quote-to-Finance」の全フローをカバーする：

```
商品ページ → 月額試算 → 仮審査 → 本審査 → 電子契約 → 納品/検収 → 販売店支払 → 月額請求 → 満了処理
```

### 1.3 対象ユーザーと提供価値

| ユーザー | 役割 | 提供価値 |
|---------|------|---------|
| 買い手企業 | 中小企業・個人事業主・工場・建設会社等 | 高額設備を月額で導入。商品詳細画面からそのまま試算・仮審査 |
| EC事業者/販売店 | 高額アセットを販売するB2B EC事業者 | ファイナンス導線で成約率向上。検収後に一括支払を受領 |
| ファイナンス提供者 | リース会社・割賦販売会社の審査担当 | API経由でアセット/法人/販売店情報を取得。リスク評価・ステータス管理 |

### 1.4 対象アセットカテゴリ

- 中古建機（油圧ショベル等）
- フォークリフト
- 工作機械（マシニングセンタ等）
- 産業機械
- 業務用厨房機器
- 冷凍冷蔵設備
- ロボット・搬送設備

## 2. 技術スタック・アーキテクチャ

### 2.1 技術スタック

| 層 | 技術 | 備考 |
|---|------|------|
| フレームワーク | Next.js 14 (App Router) | TypeScript |
| UI | React 18 | クライアントコンポーネント中心 |
| スタイル | Tailwind CSS | B2B金融調のカラーパレット |
| UIコンポーネント | shadcn/ui | Button, Card, Dialog, Table, Badge, Tabs等 |
| モックAPI | Next.js Route Handlers | `/app/api/` 配下 |
| データストア | TypeScriptオブジェクト/JSON | ランタイムインメモリ（再起動でリセット） |
| 外部依存 | なし | 外部API・外部DB不要 |
| 認証 | なし | ロール切替はヘッダーのセレクターで実現 |

### 2.2 アーキテクチャ概要

## 4. 実装方針・制約

### 4.1 実装方針

| 項目 | 方針 |
|------|------|
| データ永続化 | インメモリ（TypeScript配列）。再起動でリセット。プロトタイプとして十分 |
| 状態管理 | React useState / useContext。状態管理ライブラリ不要 |
| APIコール | fetch API を使用。SWR等のキャッシュライブラリは不要 |
| フォームバリデーション | HTML5バリデーション + 簡易チェック。React Hook Form等は不要 |
| エラーハンドリング | 最小限。APIは常にモックデータを返すため |
| テスト | 不要。PoCプロトタイプのため |
| 国際化 | 不要。日本語のみ |
| アクセシビリティ | shadcn/ui標準のa11yのみ |
| デモ用プリフィル | 申込フォームに「サンプル入力」ボタンを配置 |

### 4.2 制約・注意事項

- 本番審査や個人情報処理は行わない
- 実在企業の情報は使用しない（すべて架空データ）
- 金融商品としての正確性より、API利用イメージと業務フローの分かりやすさを優先
- 全ページに「本画面はPoC用モックであり、実際の審査結果ではありません」を表示
- 外部API・外部DBに一切依存しない
- `npm install && npm run dev` で即座に起動できること
