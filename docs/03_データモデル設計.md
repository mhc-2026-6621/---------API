# データモデル設計

## エンティティ一覧

| エンティティ | 概要 | 主キー | 保持先 | 備考 |
|---|---|---|---|---|
| Asset | 販売アセット（建機・産業機械等） | assetId | インメモリ配列 | 4件のモックデータ |
| Seller | 販売店 | sellerId | インメモリ配列 | |
| Buyer | 買い手企業 | buyerId | インメモリ配列 | |
| Quote | 月額試算見積 | quoteId | インメモリ配列 | API呼出時に生成 |
| Application | ファイナンス申込 | applicationId | インメモリ配列 | 状態遷移あり |
| Payout | 販売店支払記録 | payoutId | インメモリ配列 | |

## ER概要

```text
Seller 1 --- * Asset
Buyer 1 --- * Application
Asset 1 --- * Quote
Asset 1 --- * Application
Application 1 --- 0..1 Payout
```

## 状態定義

### Application ステータス

| 状態 | 説明 | 次に進める状態 |
|---|---|---|
| pre_screening | 仮審査中 | pre_approved, rejected |
| pre_approved | 仮承認 | full_review |
| full_review | 本審査中 | approved, rejected |
| approved | 承認済 | contracted |
| contracted | 契約済 | delivered |
| delivered | 納品済 | accepted |
| accepted | 検収完了 | payout_scheduled |
| payout_scheduled | 支払予定 | payout_completed |
| payout_completed | 支払完了 | （終了） |
| rejected | 否決 | （終了） |

## データ保持方針

- 永続化方式: インメモリ（TypeScript配列）、再起動でリセット
- 監査ログ: なし（PoC）
- 論理削除/物理削除: 該当なし
- 個人情報/機密情報: すべて架空データ
- バックアップ: Git管理のみ
