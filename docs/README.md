# docs

エンベデットリースAPIの設計資料を管理します。

## 正本ルール

- 更新対象の正本は、番号付きドキュメント（`00_サービス概要.md` から `09_将来拡張計画.md`）です。
- `adr/` は採用した設計判断を記録します。
- `design/` は画面ラフ、スクリーンショット、画像素材を管理します。
- 旧形式のドキュメントは削除済みです。新しい設計変更は番号付きドキュメントへ反映します。

## ファイル一覧

| ファイル | 目的 |
|---|---|
| `00_サービス概要.md` | サービスの目的、対象ユーザー、価値、スコープ |
| `01_フォルダ構成.md` | 設計資料と実装の正本、配置ルール |
| `02_画面設計.md` | 画面一覧、遷移、主要UI |
| `03_データモデル設計.md` | エンティティ、ER、状態、データ保持方針 |
| `04_API設計.md` | API一覧、リクエスト/レスポンス、外部連携 |
| `05_ユーザーフロー設計.md` | ロール別業務フロー、デモシナリオ |
| `06_ロール・権限設計.md` | 権限マトリクス、操作可否 |
| `07_非機能・運用設計.md` | セキュリティ、監視、ログ、性能 |
| `08_UI・デザインガイドライン.md` | デザイン原則、カラーパレット、表記 |
| `09_将来拡張計画.md` | ロードマップ、拡張候補、移行方針 |
| `adr/` | Architecture Decision Record |
| `design/` | 画面ラフ、スクリーンショット |
