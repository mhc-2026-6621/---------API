| ファイル | 目的 |

| `00_サービス概要.md` | サービスの目的、対象ユーザー、価値、スコープ |
| `01_フォルダ構成.md` | 設計資料と実装の正本、配置ルール |

| `04_API設計.md` | API一覧、リクエスト/レスポンス、外部連携 |
| `05_ユーザーフロー設計.md` | ロール別業務フロー、デモシナリオ |
| `06_ロール・権限設計.md` | 権限マトリクス、操作可否 |
| `07_非機能・運用設計.md` | セキュリティ、監視、ログ、性能 |
| `08_UI・デザインガイドライン.md` | デザイン原則、カラーパレット、表記 |
| `09_将来拡張計画.md` | ロードマップ、拡張候補、移行方針 |
