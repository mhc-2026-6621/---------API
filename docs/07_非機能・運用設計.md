# 非機能・運用設計

## セキュリティ

- 認証: なし（PoCプロトタイプ、ヘッダーのロール切替で代替）
- 認可: ロールベースのUI表示制御のみ
- 入力検証: HTML5バリデーション + 簡易チェック
- 監査ログ: なし（PoC）
- 秘密情報管理: なし（外部依存なし）

## 性能

| 項目 | 目標 | 測定方法 |
|---|---:|---|
| 初期表示 | 3秒以内 | ブラウザDevTools |
| API応答 | 200ms以内 | APIコール確認パネル |
| 同時利用者数 | 1〜3名（デモ用） | - |

## 可用性・復旧

- 稼働時間: デモ時のみ
- バックアップ: Git管理
- 復旧目標時間: -（PoC）
- データリセット: サーバー再起動で初期データに復帰

## 監視・ログ

| 種別 | 内容 | 保持期間 | 確認先 |
|---|---|---|---|
| アプリログ | Next.js コンソール出力 | セッション中 | ターミナル |
| APIログ | APIコール確認パネル | セッション中 | ブラウザUI |

## リリース運用

- ブランチ戦略: main ブランチのみ（PoC）
- 環境: ローカル開発環境
- デプロイ手順: `npm run dev` でローカル起動（ポート3001）
- ロールバック手順: `git revert` または `git checkout`
