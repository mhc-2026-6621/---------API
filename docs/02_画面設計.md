## 1. 共通レイアウト

```
┌──────────────────────────────────────────────────────────────────┐
│  [Logo] エンベデットリースAPI    [Marketplace] [申込管理]           │
│                                    [販売店] [管理者]  ロール:[▼ Buyer] │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│                        メインコンテンツ                             │
│                                                                  │
│                                                  ┌──────────┐   │
│                                                  │ </> API  │   │ ← トグルボタン
│                                                  └──────────┘   │
├──────────────────────────────────────────────────────────────────┤
│  ⚠ 本画面はPoC用モックであり、実際の審査結果ではありません          │
└──────────────────────────────────────────────────────────────────┘
```

**ヘッダー（`GlobalHeader.tsx`）：**
- ロゴ + サービス名
- ナビゲーション（ロールに応じて表示項目変更）
  - Buyer: Marketplace / 申込管理
  - Merchant: Marketplace / 販売店ダッシュボード
  - Finance Admin: 管理者ダッシュボード / 全申込一覧
- ロール切替セレクター（右端）

**フッター（`PocDisclaimer.tsx`）：**
- PoCモック注意表記（全ページ共通）

**APIコール確認パネル（`ApiCallViewer.tsx`）：**
- 画面右下にフローティングボタン `</> API` を配置
- クリックで右サイドからスライドインするドロワーパネルを表示
- パネル内容：直近のAPIコール履歴（メソッド、エンドポイント、Request、Response、ステータスコード、レスポンスタイム）
- 閉じるボタンで非表示に戻る
- ロールに関わらず全画面で利用可能

- 「リース/割賦導入により、高額商品の成約率を改善」
- 「検収後、販売店へ一括支払」
- 「買い手は月額払い」

## 10. コンポーネント設計

### 10.1 共通コンポーネント（`components/shared/`）

#### `ApiCallViewer`（APIコール確認パネル）

トグル式のフローティングドロワー。事業説明時にAPI利用イメージを視覚化する。

```
Props:
  - entries: ApiCallEntry[]    // APIコール履歴

State:
  - isOpen: boolean            // パネルの開閉状態
```

- 画面右下にフローティングボタン `</> API`
- 未読APIコール数をバッジ表示
- 右からスライドインするドロワーパネル（幅480px）
- APIコール履歴をカード形式で新しい順に表示
- Methodバッジ（GET=緑、POST=青、PATCH=黄）+ エンドポイント
- Request/Response JSONは折りたたみ式・シンタックスハイライト付き
- レスポンスタイムは150ms〜800msのランダム値（デモ用）

#### `RoleSwitcher`（ロール切替）

```
Props: なし（コンテキストから取得）
State: currentRole: "buyer" | "merchant" | "admin"
```

#### `YenAmount`（円金額表示）

```
Props:
  - amount: number
  - size?: "sm" | "md" | "lg"
  - label?: string              // 「月額」等のプレフィックス
  - suffix?: string             // 「〜」等のサフィックス
  - highlight?: boolean         // ティール色強調
```

#### `StatusBadge`（ステータスバッジ）

```
Props:
  - status: ApplicationStatus
  - size?: "sm" | "md"
```
