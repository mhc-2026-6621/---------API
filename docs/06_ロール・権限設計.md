# ロール・権限設計

## ロール一覧

| ロール | 説明 | 主な操作 |
|---|---|---|
| Buyer | 買い手企業 | 商品閲覧、月額試算、仮審査申込 |
| Merchant | EC事業者/販売店 | 商品閲覧、申込状況確認、支払予定確認 |
| Finance Admin | ファイナンス管理者 | 審査キュー管理、リスク評価、ステータス変更 |

## 画面権限

| 画面 | Buyer | Merchant | Finance Admin | 備考 |
|---|---|---|---|---|
| マーケットプレイス | read | read | none | |
| 商品詳細+月額試算 | full | read | none | |
| 仮審査申込 | full | none | none | |
| 申込詳細 | read(自分) | read(自店) | full | |
| 販売店ダッシュボード | none | full | none | |
| 管理者ダッシュボード | none | none | full | |

## 操作権限

| 操作 | Buyer | Merchant | Finance Admin | 備考 |
|---|---|---|---|---|
| 月額試算 | Yes | No | No | |
| 仮審査申込 | Yes | No | No | |
| ステータス変更 | No | No | Yes | |
| 検収登録 | No | Yes | No | |
| 支払処理 | No | No | Yes | |

## データスコープ

- Buyer: 自分の申込のみ
- Merchant: 自店舗経由の申込のみ
- Finance Admin: 全申込を参照・操作可能
